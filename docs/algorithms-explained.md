# Nesio 背后的算法：写给普通人看的一份说明

这份文档不写代码，只讲"每个聪明的地方，到底是怎么想出答案的"。目标：一个不写程序的人也能看懂，并且知道**哪里是真会学、哪里是固定规则、哪里是外接大模型**。

Nesio 的算法分三层：

1. **会学的那层** —— 用得越多越懂你（本地学习，不上传）。
2. **外接大模型那层** —— 聪明的文字/理解，交给 Claude / Gemini。
3. **固定规则那层** —— 设计者定好的、稳定不变的判断。

---

## 第一层：会学的那层（越用越懂你）

这层的共同特点：**它会看你的行为/数据，慢慢调整自己**。但要说清楚——这里只有一个是真正的"机器学习"（引导排序），其余是"经典自适应统计"（会根据数据变，但不是训练神经网络）。

### 1. 引导卡排序 —— 唯一的"真机器学习"

**它解决什么**：Today 首屏一次最多放几张提醒卡。哪几张？按什么顺序？

**老做法**：设计者写死一个打分公式——风险占 30%、时效 25%、提前价值 20%、可靠度 15%、相关度 10%，加权求和，分高的排前面。问题是：这套比重对所有人都一样，你用一年它也不会更懂你。

**新做法（会学）**：把排序换成一个**在线学习的小模型**（逻辑回归）。
- 它给每张卡算 7 个"特征分"：上面那 5 个，**外加两个只属于你的**——「这个时段你平时爱不爱理提醒」「这类卡你平时理不理」。
- 你每次对卡片点「有用 / 太多」，就是给它一个"对/错"的答案。它据此把自己的比重挪一点点（标准的梯度下降，一次一小步）。
- **最妙的一点**：它**第一天的比重就等于老公式**（新的两个特征起步为 0）。所以刚装上就和以前一样好，**绝不会更差**；只有你用起来、给了反馈，它才开始往"你的口味"偏。

**一个真实例子**（我们跑过模拟）：一个"只在晚上、只对晚间提醒行动"的人，喂 120 次反馈后，"你的活跃时段"这个特征的比重从 0 涨到 1.35；同样两张卡里，原本排前面的"早上高危卡"被"晚上的低危卡"反超了——**它学到了这个人的作息**。这是固定公式永远做不到的。

**边界**：它只学"排序"，不学"该不该出卡"——是否值得打扰你，仍由固定规则把关（学歪了也不会漏掉重要提醒或狂刷）。而且更新有上下限，不会跑飞。全部在你手机本地学，不上传。

### 2. 五个"经典自适应"组件（会根据数据变，但不是训练）

| 组件 | 它学什么 | 怎么学（大白话） |
|---|---|---|
| **精力基线** | 你个人的精力"正常水平" | 每次自报精力，用滑动平均更新一个属于你的基准线；今天比你自己的基准低一个标准差 → 提示"今天偏累"（不是跟别人比，是跟你自己比）|
| **情绪漂移** | 你是不是在持续走低 | 累计法（CUSUM）：偶尔情绪低不报警，只有**持续**往下才提示，区分"今天不爽"和"这阵子真的不对劲"|
| **联系节奏** | 你和每个人多久联系一次 | 看你和这个人过去所有联系的时间点，算出真实间隔（中位数）当"该联系"的标准——而不是"朋友一律一个月"这种一刀切 |
| **消费分类** | 一笔钱该归哪类 | 从**你自己改过的分类**里学：你把 Wegmans、Trader Joe 都归过"食品"，下次遇到 "Joe Market" 它也猜"食品" |
| **金句偏好 / 实验相关性** | 你爱哪类句子；某习惯和某结果有没有关系 | 偏好会随反馈变、还会慢慢淡忘旧口味（不会被锁死）；相关性只有**统计上显著**才敢说"有关系"，样本太少只说"还要多记几天" |

**这层的诚实话**：它们让 Nesio "越用越贴合你的基线和习惯"，但本质是**参数拟合 + 显著性检验**，不是"学到新能力"。它们现在都做到了三件事：**从你的数据学、有上下限不跑飞、不夸大（没把握就说没把握）**。

### 3. 透明面板（让学习看得见）

在「洞察 → 认知」页顶部，有一块「Nesio 学到了什么」：它诚实地告诉你——排序学习器学了多少次、现在最看重哪个信号、它觉得你几点最愿被提醒。全在本机、冷启动等于通用规则、越用越贴合。**不假装，可查证**。

## 第二层：外接大模型（聪明的文字，交给 Claude / Gemini）

这层是 Nesio "会说话、会理解"的部分。**它本身不在本地学习**——它每次的"懂你"，来自我们把你的相关记忆和上下文喂进它的提示词里，不是它记住了你。

| 功能 | 它在做什么 | 关键设计 |
|---|---|---|
| **问一问（chat）** | 基于你的记忆回答问题 | 先在本地把最相关的记忆捞出来喂给模型;**要求模型自报"我用了哪几条"**,只把它真用到的记忆做成可点的引用卡（不伪造"依据"）|
| **拍一下（analyze）** | 认出照片/语音里是什么，转成记忆 | 模型只负责识别，**存哪、去不去重由本地统一管**（同一张照片不会存两份）|
| **认知模型（living-model）** | 从你的行为统计里，推断七层"自我画像" | 你的 ✓/✗ 会进下一次推断；**失败时明说**是"AI 没配好"还是"数据不够"，不再默默空白 |
| **语义检索（embed）** | 让"产品相关"能匹配到英文邮件（跨语言）| 没配 AI key 时会退回关键词匹配，并**明确提示你**"这次只用了关键词，跨语言的可能没找全" |
| **每日简报 / 拆任务 / 起草回信 / 卡片措辞** | 播报当天、把大任务拆小、帮你写邮件初稿、把提醒改得更像人话 | 都由模型生成、你过目;起草的邮件**永远你亲手点发送** |

**这层的诚实话**：这是最"聪明"的部分，但这份聪明是租来的（外部模型），它不会因为你用得多而更懂你——每次都靠我们喂的上下文 + 你的反馈折进下一次。想让它"记住你"，得靠第一层把你的偏好持久化下来、再喂给它。

## 第三层：固定规则（稳定、可预期、不乱变）

这层是设计者定好的判断，**不随使用改变**——这是好事：有些事就该稳定、可解释。

- **引导管线的闸门**：一张卡到底值不值得打扰你（后果严重度、行动窗口是否还开着、注意力预算、冷却时间）——这些是保守的安全阀。
- **运动状态**：从你的训练打卡 + 健康指标，按规则推"体能上升/维持/下降"（不是 AI，是明写的规则，可解释）。
- **健康叙事**：把血糖/体重等冷数字变成一句话趋势（"近 3 个月下降，好"），加峰谷/异常标注。
- **地点分类**：把足迹里的地点按关键词归类（餐饮/购物/医疗…），认不出就问你。
- **DEC / 信号**：把邮件、日历、照片统一成"信号"事实流，再由规则生成 Today 卡。
- **冷冻仓 / 奖励经济**：忍住不买 +10 分、健身完成 +20 分、愿望成本=原价…这些数字是设计者定的"游戏规则"，集中在一处、想调平衡改一行。

**这层的诚实话**：这些数字和规则是人定的，用一年也不变。这不是缺点——排序可以学、但"要不要打扰你"这种事，宁可用稳定可解释的规则兜底。

## 那个关键问题：怎么让它"一出场就已经很聪明，后面只是更聪明"？

这是整套设计的核心原则，一句话：**把专家规则当"先验"，把学习当"微调"。**

具体三步：

1. **冷启动 = 当前最好的固定规则。** 学习模型初始化成设计者调好的那套比重（不是随机、不是空白）。所以第一天它的表现 = 那套精心设计的规则，**已经很好，绝不更差**。（引导排序就是这么做的：初始权重就是老公式。）

2. **有数据就从数据学，没数据就用聪明的默认。** 联系节奏：联系过 3 次以上就用你的真实间隔，不够就退回"按亲疏分桶"这个合理默认。消费分类：你纠正过就学你的，没纠正过就用关键词规则。冷启动那天全是合理默认，之后每一天都更贴合。

3. **诚实标注"我现在有多确定"。** 相关性不显著就说"还要多记几天"，语义检索降级就提示"这次只用了关键词"。**宁可说"我还不确定"，也不假装懂。**

这三步合起来就是你要的效果：**装上就好用（靠专家先验），越用越懂你（靠本地学习），而且从不吹牛（靠显著性 + 诚实失败态）。**

反面教材是我们**删掉的那段**：`personalization-insights` 以前返回两套写死的剧本（"已记住 23 件事""你每周五下午特别高效"），靠一个天数标志切换——**那不是聪明，是预录**。现在它改成从你真实的记忆和连接状态实时算：第一天多半是"0 件 / 未接入"（诚实），数据长起来自动变丰富。这正是上面第 2 条原则的活例子。
