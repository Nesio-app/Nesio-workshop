# Nesio v1 产品规格 · 2026-07(回归 README 的收敛)

> 定位:**私密外置大脑——为记忆减负**(为 ADHD 设计,向大众表达,文案不提 ADHD)。
> 本文是 2026-07 真机 QA + 用户研究 + 竞品调研后的**收敛规格**,给在修 agent 执行。
> 北极星 = README(Know Less. Live More. / Context Recovery)。本文不改方向,只把产品拉回它自己的蓝图。
> 配套原型图(已交付用户):Today 三态 深/浅两版、洞察三屏。

## 0. 三条产品公理(所有决策的判据)

1. **核心循环 = 记 → 忘掉也安全 → 问/回溯把它带回来。** 大多数用户"只写不读"、记不得自己记过什么 → 检索靠"问"(按意思)不靠"搜"(按关键词);价值靠 app **主动送上门**(回溯+观察),不能等用户来翻。
2. **回溯 > 预测。** 观察过去永远"对"(那是用户自己的东西),预测未来必然翻车。全产品**禁止预测型输出**;推断类内容必须:带证据、可反驳(✓/✗)、高置信才出、低置信沉默。
3. **Calm ≠ Dead。** 少而真,但页面永远活着:没触发时显示"承诺的收据"(已替你记着 N 条),绝不空屏+说明书,也绝不硬凑噪音。

## 1. Today 页规格

**公式:一句安心(收据)+ 0-3 张到点的事(FOCUS)+ 最多 1 张回忆 + 一行捕获提示。四件封顶。**

### 1.1 组件
| 组件 | 内容 | 规则 |
|---|---|---|
| ① 安心态(首行) | 纯事实收据:"都记着呢。今天 3 条,都收好了" | 每次打开先兑现一次承诺;晚间变日终收尾;**绝不显示同步计数/技术状态** |
| ② FOCUS(0-3 张) | **只放确定性来源**:用户自设的时间/提醒、标⭐的、真到期的 | 每张带出处("你上周设的·今天到点")+ 完成/改天;没有 → 一行"✓ 没有到点的事"收掉;**未来预测卡删除** |
| ③ 回忆(≤1 张/天) | 触发优先级:**到点/答应的 > 情境相关(路线图) > 掉线线头 > 重复主题 > (二级)去年今天** | 没有强触发 → 整格消失,不硬凑;点开进记忆 |
| ④ 捕获提示 | "想到什么,**按住方块**说一句就卸下"(指向导航 FAB) | 底部捕获卡撤除——**FAB 是唯一英雄动作**;文案随时段变 |

### 1.2 时段三态
早:收据=昨天的都存着,重心 FOCUS;日间:收据=今天 N 条,重心捕获;晚(21:00+):收据=日终收尾"可以放心把今天放下了",重心回忆(上限 2 张),氛围加深/转暖。

### 1.3 新用户空态
"我在。记点什么,我替你记着。" + 放大的捕获主角带**具体例句**(「备用钥匙放在门厅抽屉」);②③不出现;记完第一条 → 收据立刻变"✓ 记下了。现在可以放心忘了。"(第一分钟完成一次承诺兑现)。

## 2. 洞察页规格(本轮新增)

### 2.1 免费层:八模块 → 四件
**保留:**
1. **你在想什么(主题门)**——embedding 聚类,暖色门卡"搬家 · 7 条 ›",点进合集;开场一句宋体嗓音("七月,占着你脑子的是——")
2. **没接上的线头**——"12 个想法没再碰,最老:两个月前「学木工」›"
3. **走走看**——随机翻一条 + 去年今天(Today 之外满足"想多看"的地方)
4. **一行节律**——"本月 42 条 · 多在晚上 · 说的比打的多" + 迷你柱线(心情均值并入此行)

**删除:**统计卡×4、139 数字行、**记录分布饼图**、**活动热力图**、跨区洞察空状态(v1 域已砍,文案已过时)、今日时间块、生活报告(独立区)。
**保留的诚实声明**(页脚):"全部来自本地统计 · 无 AI 推断 · **批量导入不计入**"。
"NESIO 学到了什么"卡保留(信任资产),移设置或页底。

### 2.2 生命版图:唯一保留的图
- `LifeCivilizationMap` 升格为洞察的 hero 视觉;顶部一句宋体解读(现有"最大迁移"标注机制保留)+ 证据行("基于 N 条记录的意义密度")。
- **规则:不满 90 天数据不出现;绝不以示例地形冒充**(现状 `LifeCivilizationMap.tsx:327` 稀疏时显示示例——违反诚实原则,改)。
- 顺手消灭数据打架:`InsightsSheet.tsx:203` 自曝 domain 有三套定义(context.domain ?? tags[0] ?? typeLabel)与饼图/版图互搏——删饼图后统一到版图一套。

### 2.3 认知 → Pro「多面镜」
- **地基已存在**:`InsightsSheet.tsx:561` 已有视角机制(CBT lens + "选择一个视角重新分析")。扩展视角库并挂 Pro 门。
- **形态:每月一封信。** 选一面镜子,它读你的本地档案,写给你(第二人称、宋体、暖色):
  - **老友**(默认,免费可试读):温暖直白
  - **苏格拉底**:不下结论,只把你的矛盾变成问题
  - **荣格**:反复出现的意象、你回避的主题
  - **盲区侦探**:你从不记什么("你记别人很多,记自己感受的只有 3 条")
  - **斯多葛**:你惦记的事里哪些真的可控
- **规则**:只回看不预测(现有"预测"分区退役,"演化"保留);每封带证据 chips + ✓说得对/✗不像我(接现有反馈环);低置信不写;**批量导入(如 Google 通讯录 127 人)剔出证据**——否则镜子读到的是通讯录不是用户;认知关系图(节点图)移 Lab。
- **口吻**:废除"用户是一个…的个体"实验报告腔;对"你"说话。
- **为什么 Pro**:多视角综合+文笔是云 LLM 不可替代处,与"月度回顾"合并为同一 Pro 卖点。

### 2.4 业界依据
Gyroscope/Felton(大数字+叙事+精选卡,个人数据=编辑过的刊物而非监控台)、Spotify Wrapped(一屏一洞察)、Apple 健康摘要(优先级卡)、Exist/Bearable 反例(数据墙=信息过载流失)。

## 3. 标签系统:三层模型 + 「标签=门」判据

### 3.1 现状(代码证据)
三套系统撞车:①`node.type`(7 种)→ NodeTypeIcon 卡片图标一;②`domain`(5 域)→ DomainIcon 卡片图标二——**object/assets 都映射 IconBox → 双立方体 bug**(`MemoryTab.tsx:581` 批次13补丁只修了 health 对);③`node.tags[]` 自由文本(AI 无词表约束 `extraction.ts:24` → "餐具/玻璃/水杯"同义堆积)在详情页**全量渲染**(`MemoryNodeDetail.tsx:862-864`)。且 tags 兼职决定 sensitivity/retention(`signal.ts` inferSensitivity/inferRetention 关键词匹配)。

### 3.2 新模型
```
L1 结构层(封闭词表·字段) → 机器:图标/路由/敏感度/保留/过滤 —— 每卡恰好 1 个图标
L2 语义层(开放·仅索引)   → 机器:检索召回/聚类原料 —— 永不上 UI
L3 主题门(涌现·有门槛)   → 人:唯一可见"标签",形态是门不是签
```
- **L1 type→图标表**:object📦物品 / note📝想法(默认) / commitment🚩答应的事 / event📅事件 / person👤人 / place📍地点 / preference⭐喜好 / health_state(v1 隐藏)。**domain 第二图标废除**。
- **L2**:AI 标签指令改为"检索用途、可冗余、不展示"(解除模型审美负担);normalizer 系统标('手动记录'等)归此层。
- **L3 门槛**:同主题 **≥3 条** + 聚类置信过线 + 每处 **≤2 扇**;形态永远 `搬家 · 7 条 ›`(可点有去处)。
- **总判据:标签只在"是一扇门"时露面;描述用户眼前已见之物的一律进索引不上屏。**

### 3.3 改动点
1. `MemoryTab.tsx:581-585` 删 domain 图标;列表卡加**照片缩略图**(视觉记忆视觉化)+ 相对时间("昨天")。
2. `MemoryNodeDetail.tsx:862-864` 删 tags 全量 chips → L3 门组件;`RelationGraph` 移出详情页(→Lab),换"相关记忆"列表;"记录于 2026年7月9日"→ 相对时间("今天 12:34")。
3. `extraction.ts` tags 指令改写。
4. 中期:sensitivity/retention 改为 L1 枚举字段直读,摆脱自由文本依赖(写入固化已是现状,推断只兜底)。

## 4. 视觉设计系统(UI 意见汇总)

1. **冷暖物理学**:现在/计划 = 冷蓝;**过去/回忆 = 琥珀暖**(卡底微暖渐变+暖金图标)。贯穿 Today 回忆卡、洞察主题门、多面镜信纸。
2. **双声道字体**:**Nesio 说话(安心态/洞察开场/月度信)用宋体**(Songti SC/Noto Serif SC);数据/操作用黑体。数字 tabular-nums。
3. **图标纪律**:全线性单色、同笔画宽(≈1.5px)、与立方体 logo 同语言;**emoji 禁止用作图标**;每卡 1 个图标。
4. **时间改变房间光线**:晚间深色更深/浅色纸转暖(奶油)。
5. **单一英雄动作**:导航中央 FAB = 捕获,全 app 不再有第二个捕获入口;"按住方块说一句"作为仪式动作。
6. **章节标签能删则删**(FOCUS/回忆等 eyebrow 冗余即去);中文全角标点。
7. **动效**(实现时单列):回忆卡"从深处浮上来"(上移+淡入)、收据逐字落定(每日首开)、按住方块时立方体呼吸发光;全部尊重 prefers-reduced-motion。
8. **图表纪律**:洞察只留生命版图一张图;任何图不满数据门槛不出现;节点图(关联地图/认知关系图)一律 Lab。
9. 主题一致性:设置页深色失效(QA)修复;洞察 tab 栏中英文粘连溢出修复(单页化后自然消失)。

## 5. 捕获管线

1. **先落库,后分析**:捕获即本地保存("✓ 记下了"瞬间、离线可用),AI 分析一律异步后补。**"识别中"不得阻塞保存**。
2. **免费 = 端上/确定性,Pro = 云深度**。现状:拍一拍/说一句/分享**三个入口全打云 `/api/portal/analyze`**(CameraSheet/VoiceInputSheet/ShareSheet)——改:
   - 说一句:端上转写(iOS 已是)+ 规则抽时间/意图;云 LLM 意图 = Pro
   - 拍一拍:端上视觉标签;云场景理解 = Pro
   - 分享:抓标题正文存档;AI 摘要 = Pro
   - 检索地基:端上 embedding(已有 signal-embedding)
3. 自动打标签合理且必要,但按 §3 三层归位;**匿名/免费永不因打标签产生云调用**。

## 6. 权限三道门 + QA 缺陷清单

三道门(内测版全开是常态,**上线前必须全部变真**):
**① 登录门**(匿名 vs 登录)· **② 付费门**(免费 vs Pro——现状是桩,STATE.md 自认"真权益强制层未落地")· **③ 提审门**(APPSTORE_BUILD=1 → v1 砍的域+Lab 不可达)。

### P0(伤信任/漏钱,上线前必改)
1. **"1565 待同步"提示**:数字是底层 signal 计数非用户记忆;匿名无从同步却显示;正面反噬"记下就安全"。→ 匿名不显示任何同步状态;状态默认隐形、措辞安心("已保存在本机");不暴露内部计数。
2. **匿名可打云 AI**(问一问/识图/语音/TTS 朗读):烧钱+可刷+隐私。→ 匿名/免费走端上,云 AI 登录+限流起步,深度=Pro;验收:匿名状态云 provider 调用=0。
3. **Pro 功能未挡**(冷冻仓等):entitlement 桩→真强制;免费点击=升级引导。
4. **跨账号本地数据泄漏**:换账号登录仍见前一账号的记忆/通讯录。→ 本地存储按 userId 命名空间隔离;切换需清退/切换;匿名→登录合并显式确认。验收:登录 B 看不到 A 任何数据。
5. **匿名可连 Gmail**(无主 OAuth token)。→ 连接私有数据源(邮箱/日历/银行)必须先登录(落实 anonymous-private-data-gate 到 UI)。

### P1
6. 账号系统三缺:设置页无账号区(当前邮箱/登出/删除账号入口——5.1.1 正好一起接)、注册与登录流程无区分、引导称呼与头像不同步("J" vs "Me")。
7. 设置页深色主题失效。
8. 洞察 tab 粘连溢出(单页化消灭)。
9. **健身模块(Training Plan/Exercise Library)纳入 v1 隐藏范围**(与健康/财务/足迹/人员/Lab 同批,提审版不可达——Lab 可达=Guideline 2.3.1 违规)。
10. Reader 定位拍板:捕获源(留,纯本地)vs 独立阅读器(v1 Default-off);**Listen 朗读(云 TTS)匿名/免费不可用**。

## 7. 验收总纲

- 匿名:能记/看金句/设称呼/本地问,**不打云、不见同步数字、不碰 Pro、连不了邮箱**。
- 免费登录:+ 云同步备份 + 端上 AI;云 AI 限流。
- Pro:+ 冷冻仓 + 深度云 AI(问答/深识图/意图/摘要)+ 多面镜月度信。
- 提审版:健康/财务/足迹/人员/健身/Lab 全不可达。
- Today:四件封顶、无预测、空态是收据不是说明书。
- 洞察:免费四件套 + 生命版图(≥90 天),无饼图/热力图/节点图;认知=Pro 多面镜,只回看、带证据、可反驳。
- 标签:每卡 1 图标;详情页无原始 AI 标签;可见标签只有 ≥3 条的主题门。
