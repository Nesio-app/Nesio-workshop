5️⃣  风险评估
════════════════════════════════════════════════════════════════════════════════

    🔴 高风险
    ├─ localStorage 已占用 localStorage 配额的 65-95%（接近爆满）
    ├─ 重用户（10-15 MB）已超出标准 5-10 MB 配额
    ├─ 写入失败率 2-5%，高峰期达 5-10%
    ├─ 无主动清理机制，累积压力只增不减
    └─ 生活图谱逐日增长，预期 3-6 个月内触发功能中断

    🟠 中等风险
    ├─ 云同步排队（outbox）可能在 localStorage 爆满时失败
    ├─ 离线状态下新建数据可能无法保存
    ├─ 跨端同步中，某一端 localStorage 爆满导致数据不一致
    └─ 缓存层与数据层混储，难以管理生命周期

    🟡 低风险
    ├─ UI 状态占用小，但也挤占了数据的宝贵空间
    ├─ 已废弃的 key（theme-lowsat 等）仍占用 ~20 KB
    └─ 秘密数据（tokens）明文存储，隐私风险

6️⃣  改造方案概览
════════════════════════════════════════════════════════════════════════════════

    ┌─────────────────────────────────────────────────────────────┐
    │  三层存储架构（推荐方案）                                  │
    ├─────────────────────────────────────────────────────────────┤
    │                                                             │
    │  第一层：IDB 永久表（用户数据 + 云同步）                   │
    │  ┌──────────────────────────────────────┐                  │
    │  │ life-graph, bank-tx, health,         │                  │
    │  │ profile, projects, relationships etc.│ 10-20 MB        │
    │  │ TTL: 无限 | 上云: 是 | 加密: 可选    │                  │
    │  └──────────────────────────────────────┘                  │
    │           ↓                                                  │
    │  第二层：IDB 临时表（缓存 + 同步状态 + 1 周 TTL）          │
    │  ┌──────────────────────────────────────┐                  │
    │  │ sync-state, api-cache, revgeo-cache │                  │
    │  │ TTL: 7 天 | 上云: 否 | 自动清理: 是  │ 1-2 MB          │
    │  └──────────────────────────────────────┘                  │
    │           ↓                                                  │
    │  第三层：SessionStorage（UI 状态，本会话 TTL）            │
    │  ┌──────────────────────────────────────┐                  │
    │  │ tips-shown, theme-palette etc.      │                  │
    │  │ TTL: 浏览器关闭 | 自动清空: 是        │ <100 KB         │
    │  └──────────────────────────────────────┘                  │
    │                                                             │
    │  localStorage（保留）：< 100 KB                            │
    │  ├─ SSR 首屏渲染（主题等）                                 │
    │  ├─ 老旧浏览器 fallback                                   │
    │  └─ IDB 初始化前的引导                                     │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
