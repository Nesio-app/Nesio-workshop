A single lightweight floating entry. The shell uses two: 笔记 (note) and 智友 (AI). Keep them to one tap — they open floating windows, never full tabs.

```jsx
<FloatingButton icon="💬" position="br" accent label="智友" />
<FloatingButton icon="✎" position="bl" />
```

`icon`, optional `label` (makes a pill), `accent` (filled blue), `position` (br/bl/tr/tl), `size`. Fixed-positioned with safe-area insets.
