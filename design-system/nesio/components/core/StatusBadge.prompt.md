Warm-coach status pill. Communicate state without alarm — most things are `gentle` or `calm`, success is `go`, and `risk` (muted red) is only for genuine expiry/safety.

```jsx
<StatusBadge status="gentle" dot>可以稍后</StatusBadge>
<StatusBadge status="risk">3 天后过期</StatusBadge>
```

Never use `risk` for an ordinary overdue to-do — that breaks the no-anxiety rule. Prefer `gentle`.
